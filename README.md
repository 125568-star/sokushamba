# SokoShamba

Static Kenyan farmers marketplace concept based on the original farmer-and-produce design.

Live: https://125568-star.github.io/sokushamba/

Deploy using GitHub Pages from `main`, `/ (root)`. No build step or dependencies.

The home page, Buy, Sell, Categories, How It Works, About, Login and Sign Up have dedicated HTML pages. Nine category pages and six product pages support direct links. All page content and sample listings are present in HTML; JavaScript adds search and local listing drafts.

Accounts, public seller listings, seller contact, ordering, payments and delivery booking are not connected. Drafts are stored only in the current browser and can be reviewed on drafts.html.

Original category and listing photographs are bundled in assets. The hero was cleaned from the original concept using image generation so headings and search remain responsive HTML.

Every page includes an English / Kiswahili language switch; the selected language is remembered in the browser.
